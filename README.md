# JWT vs Sessions vs OAuth 🔐

This is a basic project that explains in a simple way the differences between **JWT (JSON Web Token)**, **Sessions**, and **OAuth**.

## 🧠 What you'll find in this repository

A few simple examples and code comments that help you understand:

- What JWT is and how it’s used for authentication.
- How session-based authentication works using cookies.
- What OAuth is and how it differs from the other methods.

This is **not** a production-ready implementation — it's just a small educational project to help visualize how these concepts work.

## 🛠️ Technologies used

- Node.js
- Express
- (Plus a bit of plain HTML to test some endpoints)

## ✅ Purpose

This project was created for learning purposes. If you're getting started with web authentication, this repository can help you understand the basics of each method.
